# Vaporwave · ネオンの道

カメラを固定し、紫の格子の地形と左右の浮かぶネオン文字を手前へ流す。奥には横縞の夕日を置く。

地形は幅64、奥行き32の区間を1単位の格子で作り、左右の頂点の高さを変えて山にする。中央12単位は高さ0の平らな道として残し、両端をピンクの線で示す。道から山へ滑らかに立ち上げ、Z方向の高さは32単位周期にして隣の区間とつなぐ。線は縦横だけを描き、三角形の対角線は入れない。

文字にはNoto Sans JPの最も細いweight 100を使う。1024×512の透明背景Canvasに文章を描画し、淡い光彩を加える。板や看板の背景は置かず、左右で水色とピンクに着色する。

同じ32単位の区間を4つ並べ、12秒で1区間進む。近くの文字は通過前にフェードアウトし、奥は霧で隠す。区間の再配置と透明度は絶対時刻から決め、12秒周期で同じ景色に戻る。

描画素材の生成、文字の見た目、移動、リソースの破棄はVaporwaveScene内で管理する。
